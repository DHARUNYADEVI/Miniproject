## Title of the Project
ElectroSave integrates AI-driven price comparison, forecasting, and energy-aware deal evaluation for electronics shopping across retailers like Amazon, Flipkart, and Croma.​

## About
<!--Detailed Description about the project-->
ElectroSave helps consumers navigate complex e-commerce by predicting future prices using machine learning, calculating energy costs, and providing total cost of ownership (TCO) analysis. The system uses Flask backend with React frontend to deliver real-time comparisons and actionable recommendations like "Buy now" or "Wait for price drop."

## Features
<!--List the features of the project as shown below-->
- Machine learning price prediction via LSTM time-series forecasting for optimal purchase timing.​
- Multi-factor deal scoring combining price, energy efficiency, and 5-year TCO.​
- Real-time data aggregation from multiple retailers with historical price charts.​
- Personalized weight sliders for price, energy, and TCO prioritization.​
- Responsive web interface with visual analytics and savings comparisons.

## Requirements
<!--List the requirements of the project as shown below-->
* Hardware: Intel/AMD dual-core processor, 4GB RAM minimum, 120GB storage, internet connectivity.​
* Software: Python 3.6+, Flask/ReactJS, TensorFlow/Pandas/NumPy, VS Code IDE, Git version control.​
* Libraries: BeautifulSoup/Selenium for scraping, scikit-learn for ML models, Matplotlib/Plotly for charts.
